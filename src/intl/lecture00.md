# CS1 Review

This is a review, not new material — a chance to check that the tools you
already built in CS1 are still in your hands before this semester starts
stacking new ones on top.

## Where this semester goes

CS2 takes the language of CS1 — functions, conditionals, loops, lists — and
starts building real programs with it. The chapters ahead work through
lists and strings, nested loops over 2-D grids, and eventually classes and
objects.

## Why start with review

Every one of those chapters assumes you can already call a function
correctly, branch on a condition correctly, and design a loop correctly.
If that assumption doesn't hold, the later material turns into a fight
with syntax instead of a fight with the actual problem. The five ideas
below — functions, conditionals, loops, lists, and the loop patterns that
combine them (min/max, counter, "for some"/"for all") — get reused, without
re-explanation, in every chapter that follows.
